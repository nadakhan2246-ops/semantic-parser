What is semantic parsing?

Semantic parsing maps a sentence written in natural language to a formal representation that a program can execute. Instead of matching keywords, it identifies who or what the sentence is about, which action is requested and which details (places, dates, objects) complete the request.

This project uses a rule-based approach: a verb lexicon, gazetteers for places, dates and objects, and weighted regular-expression patterns for intent. A weak match is reported as UNKNOWN rather than guessed.

Project purpose

Assistants, search engines and chatbots need meaning, not just words. This application demonstrates how each processing stage contributes to that meaning and makes every intermediate result visible, so the full analysis can be inspected and explained.

Technology: Python, Flask, NLTK, SQLite, HTML, CSS and JavaScript.
